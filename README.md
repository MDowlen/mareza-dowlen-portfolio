# Mareza Dowlen — AI Engineering & Software Portfolio

Public portfolio source for Mareza Dowlen, an AI engineering and software development student building grounded RAG infrastructure, multi-agent engineering tools, production AI applications, and human-reviewed automation systems.

## Featured engineering work

- **ForgeContext** — grounded developer-context infrastructure with Tree-sitter parsing, provenance-aware chunking, incremental indexing, pluggable embeddings, hybrid retrieval, Qdrant/local vector storage, dependency impact analysis, ADR/Git-history context, and retrieval evaluation.
- **ForgePR** — RAG-grounded pull-request review and CI quality-gate workflow using LangGraph, Pydantic contracts, ForgeContext evidence, structured AI findings, generated pytest execution, deterministic enforcement, GitHub integration, and evaluation.
- **ForgeIncident** — evidence-grounded multi-agent incident triage and root-cause analysis that correlates logs/metrics/traces/alerts/deployments with repository code, runbooks, ADRs, Git history, and postmortems. Model hypotheses may cite only system-issued evidence IDs.
- **Nexa** — production MERN + AI conversation workspace with React, Express, Node.js, MongoDB Atlas, Mongoose, OpenAI API integration, and Vercel deployment.
- **Sissy’s Academy** — instructor-controlled EdTech PWA with mastery routing, separate student/teacher workflows, Supabase authentication, Row Level Security, realtime updates, and offline support.
- **StitchStory** — responsive local-first craft project organizer with project tracking, materials inventory, journal, gallery, and JSON backup/restore.

## Forge ecosystem

```text
ForgeContext -> grounded repository intelligence
     |
     +--> ForgePR -> preventive PR review + deterministic CI gates
     |
     +--> ForgeIncident -> evidence-backed incident triage + RCA
```

The ecosystem is designed around a consistent principle: model reasoning should be grounded in traceable evidence, while deterministic systems and explicit human approval retain authority over risky actions.
