# Mareza Dowlen — Developer Portfolio

Public portfolio source for Mareza Dowlen, a software developer and AI Software Engineering student focused on privacy-conscious web applications, data systems, applied AI, and practical product design.

## Featured work

- Sissy’s Academy — instructor-controlled EdTech PWA with mastery routing, student/teacher views, Supabase auth, Row Level Security, realtime updates, and offline support.
- Nexa — production MERN + AI conversation workspace with React, Express, Node.js, MongoDB Atlas, Mongoose, OpenAI Responses API, and Vercel deployment.
- StitchStory — responsive local-first craft project organizer with project tracking, materials inventory, journal, gallery, and JSON backup/restore.
- PawPrint Vault — pet-care organizer with sitter workflows and practical care information architecture.
- MISO Family Base — privacy-first family planning system with local-first household workflows.

## Portfolio stack

Static HTML, CSS, and JavaScript. The site is intentionally dependency-light so it can deploy easily to GitHub Pages, Vercel, or any static host.

## Local preview

Open `index.html` in a browser, or serve the folder with any static web server.
